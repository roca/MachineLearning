# OpenCode Beginner to Pro: Agentic Coding with Free AI Models

A Udemy course by **Tom Phillips** (WebDevEducation)

## Course Details

- **Rating**: 4.7/5 (137 ratings)
- **Students**: 1,294
- **Duration**: 2h 9m (6 sections, 19 lectures)
- **Level**: Beginner to Intermediate

## What You'll Learn

- Set up and use OpenCode for agentic coding workflows with free AI models
- Build a basic Next.js app using OpenCode, AI agents, and structured prompts
- Create project rules, agent skills, and custom agents with sub agents
- Use better planning techniques to get stronger results from free models
- Install MCP server to communicate with third party tools and platforms

## Requirements

- Computer that can run a code editor, Node.js, and OpenCode
- No paid AI model subscription required (free AI models used throughout)
- Basic JavaScript, React, or Next.js knowledge helpful but not required

## Target Audience

- Beginner to intermediate developers wanting to learn agentic coding with OpenCode
- Developers interested in AI coding agents (Claude Code, GitHub Copilot, Cursor) using free models
- Students, indie hackers, freelancers, and builders wanting practical OpenCode introduction
