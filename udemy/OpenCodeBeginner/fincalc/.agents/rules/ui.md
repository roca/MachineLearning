# UI Component Standards

## Rule: Use shadcn/ui Components

All UI components in this app **must** use [shadcn/ui](https://ui.shadcn.com/) components.

### Requirements

1. **No custom components** — Do not create custom UI components. Use existing shadcn/ui components.
2. **Install from registry** — If a needed component is not installed, check the shadcn/ui registry and install it using `npx shadcn-ui@latest add [component]`.
3. **Follow shadcn/ui patterns** — Use the component's documented props, variants, and usage patterns.

### Quick Reference

- Registry: https://ui.shadcn.com/docs/components
- Installation: `npx shadcn-ui@latest add [component-name]`
